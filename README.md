# PI-SEQ — Raspberry Pi MIDI ステップシーケンサー

余ったラズパイで作る、**16ステップ × 最大32小節**の MIDI ステップシーケンサー。
GUI はブラウザ。バイブコーディング＋オープンソースだけで作っていくプロジェクト。

## できること (v0.6.13)

- **ドラムパッチ切り替え**（DRUMトラックのPATCHセレクタ）：サンプルを選ぶとCC（Drum1=CC8, Drum2=CC18, Drum3=CC44, Drum4=CC50）を送って即座に切り替え
- **＋ DRUM TRACK**：Circuit Tracks用ドラムトラックを一発追加（CH10 + ドラムマップON + ノート36）
- **トラックミュート/ソロ**（M/Sボタン）：ミュート中はそのトラックの音が即止まり、ソロ中はソロしたトラックだけが鳴る（他は暗転表示）
- **ドラムマップモード**（DRUMボタン）：ピアノロールが **Circuit Tracks のドラムパッド 36-51** にスナップし、パッド名（Kick/Snare/CH/OH/Crash…）表示
- トラックを**追加/削除/リネーム/カラー変更**できる（最大16トラック）
- **FOLLOWモード**：再生中に自動で次のバーへ画面が切り替わる
- **ピアノロール**：ノートの**右端をドラッグして長さ変更**、**和音入力**（同一ステップに複数ノート）
- 4トラック × 16ステップ × 最大32小節
- **ピアノロール**（🎹ボタン）— メロディックなトラックにステップ単位でノートを描ける
- **4パターン**（P1-P4）ワンクリック切替、パターンごとに小節数も独立
- **ソングモード**：16エントリの曲順にパターンを並べて一続きの曲として再生（パターンは自分の小節数を最後まで演奏してから次へ）
- **スイング**（裏拍の遅延 0-100%）
- **MIDI入力 + CCラーニング**：ノブ/フェーダー/ボタン付きコントローラー（Launch Control XL 3等）を直接操作面にできる。相対（エンドレス）⇔絶対（ポット）自動判別、マッピングはJSON保存
- **MIDI OUTセレクタ**：UIから出力先（シンセ）を選べる。トラックごとに別デバイス + MIDIチャンネル指定可
- ステップごとの**発音確率** (0-100%) ← IDMの心臓
- **ランダムノート**（トラックごとにスケール指定、RNDモード）
- **ヒューマナイズ**（タイミング・ベロシティの揺らぎ）
- **パラメータ記録再生**（REC onのまま再生中にツマミを動かすとオートメーション録音、ループ再生）
- 🎲 パターンランダマイズ
- MIDI出力（USB MIDI直挿し / 仮想ポート）

## 必要なもの

- Raspberry Pi（3以降、Zero 2 Wでも動くはず）
- ブラウザ（Piの画面でも、同じLANのPC/スマホからでもOK）
- MIDI音源（USB接続シンセ / PCのDAW / なくても仮想ポートで動く）

## セットアップ

```bash
# ラズパイ（Debian系）で最初にこれ
sudo apt update && sudo apt install -y python3-venv libasound2-dev build-essential git

git clone <repo-url> pi-seq
cd pi-seq
./setup.sh
```

## 起動

```bash
.venv/bin/python run.py
# → http://<ラズパイのIP>:8000 をブラウザで開く
```

MIDIポートを明示したい場合:

```bash
.venv/bin/python -c "import mido; print(mido.get_output_names())"
.venv/bin/python run.py --midi-port "UM-ONE MIDI 1"
```

送信中のMIDIを覗き見:

```bash
.venv/bin/python scripts/midi_monitor.py
```

## Windowsで動かす

1. **Python 3.11+** をインストール（[python.org](https://www.python.org/downloads/) のインストーラで「Add to PATH」にチェック）
2. リポジトリを取ってくる: `git clone https://github.com/hiro-jodai/py-seq.git && cd py-seq`
3. **`setup.bat`** をダブルクリック（venv作成 + 依存インストール）
4. **`run.bat --no-virtual`** で起動 → http://localhost:8000 をブラウザで開く

### Windowsで音を出す

- **すぐ試すだけなら**（ソフト音源・高レイテンシ）:
  `run.bat --midi-port "Microsoft GS Wavetable Synth" --no-virtual`
- **FL Studioに流す**: [loopMIDI](https://www.tobias-erichsen.de/software/loopmidi.html)（無料の仮想MIDIケーブル）をインストールしてポート作成 →
  `run.bat --midi-port "loopMIDI Port" --no-virtual` →
  FL Studioの **OPTIONS → MIDI settings** でloopMIDIをInputに追加 →
  任意のチャンネルを選択するとノートが届く（MIDI入力は選択中チャンネルに入る）

※ Windowsには仮想MIDIポートの仕組みがないので `--no-virtual` を使う（loopMIDIが仮想ポート役）。

## 使い方

- **クリック** でステップ on/off
- **M / S** ボタンでトラックのミュート/ソロ（ソロ中は他トラックが暗くなる）
- **＋ TRACK** でトラック追加、各トラックの **🗑** で削除、名前欄とカラーピッカーで変更
- **FOLLOW** ボタンで再生中に画面が再生バーを追従する（デフォルトON）
- **🎹** でそのトラックのピアノロール表示/非表示。**クリックでノート追加（同じステップに別のピッチを重ねると和音）、右クリックでノート削除、ノートの右端（白いバー）をドラッグで長さ変更**。LENで新規ノートの長さ指定。表示範囲はトラックのノート±8半音
- **ステップグリッドも右クリックで消去**（ブラウザの右クリックメニューは無効化済み）
- **P1-P4** でパターン切替（パターンごとに別のステップデータ）
- **SONG行** のセルをクリック → そのエントリのパターンを選択（1→2→3→4→1…）
- **SONG** ボタンでソングモード on/off（曲順に沿ってパターンが切り替わる）
- **SWING** スライダーで裏拍の遅延量（50% が王道シャッフル）
- **PROB モード**（ヘッダーのPROBボタン）ONにしてクリック → そのステップの発音確率をスライダー値に設定（0% で消去）
- **REC** onのまま再生中に BPM / velocity / 確率 / note を触るとオートメーション録音（CLR AUT で消去）
- **スペース** で再生/停止、**← →** で小節移動
- 各トラックの **FX/RND** で固定ノート ⇔ スケールランダム切り替え、🎲 でパターン乱数生成

### MIDIコントローラーで操作（CCラーニング）

1. MIDI INバーでポートを選んで **OPEN**（`--midi-in "ポート名"` で起動時に自動接続も可）
2. 右のドロップダウンで割り当てたいアクションを選ぶ（BPM/SWING/トラック音量/パターン切替/再生停止など）
3. **LEARN** を押す → コントローラーのノブを回す/ボタンを押す → 自動で割当完了
4. マッピングチップはクリックでrel/abs切替、右クリックで削除。**midi_map.json に保存される**

エンドレスエンコーダ（相対）とフェーダー（絶対）は自動判別される。

## Circuit Tracks（Novation）で使う

Circuit Tracks は **8トラック**（Synth 1/2, MIDI 1/2, Drum 1-4）を別々のMIDIチャンネルで受信できる。ただし**内蔵音源があるのは Synth 1/2 と Drum 1-4 の6トラックだけ**。MIDI 1/2 は外部シンセを制御するためのトラックで、本体からは音が出ない。

デフォルトのチャンネル割り当て:

| Circuit Tracks | CH | 音源 | PI-SEQでの使い方 |
|---|---|---|---|
| Synth 1 | 1 | 内蔵(ノバトーン) | メロディ/ベース |
| Synth 2 | 2 | 内蔵(ノバトーン) | メロディ/ベース |
| MIDI 1 | 3 | **外部用(音なし)** | 外部MIDIシンセ制御 |
| MIDI 2 | 4 | **外部用(音なし)** | 外部MIDIシンセ制御 |
| Drum 1 | **10** | 内蔵(サンプル) | ドラムマップ |
| Drum 2 | **10** | 内蔵(サンプル) | ドラムマップ |
| Drum 3 | **10** | 内蔵(サンプル) | ドラムマップ |
| Drum 4 | **10** | 内蔵(サンプル) | ドラムマップ |

※ **Drum 1-4 はすべて同じMIDIチャンネル（デフォルトCh10）**。そして公式のProgrammer's Reference Guideによると、各ドラムトラックは**単一のノートでトリガー**される:

| ノート | トラック |
|---|---|
| **60** (C4) | Drum 1 |
| **62** (D4) | Drum 2 |
| **64** (E4) | Drum 3 |
| **65** (F4) | Drum 4 |

設定手順:

1. MIDI OUTセレクタで **Circuit Tracks** を選択（各トラックのOUTもGLOBALのままでOK）
2. シンセ用にトラックを2つ用意し、**CHセレクタ** で 1〜2 を選択
3. ドラムは **＋ DRUM TRACK ボタン**を押す → **Drum 1-4のトリガーノート（60→62→64→65）とCH10を自動設定**。ステップグリッドをクリックするだけでドラムが鳴る
4. Setup View（Shift+Save）で**ドラムのMIDI Chが10**になってることを確認（Note Rxが緑に光ってるかも見てね）
5. 手動でやる場合: トラックの **CHセレクタで 10**、ノートセレクタで 60/62/64/65、**DRUMボタンON**

※ Circuit Tracks の各トラックのCHは本体側でも変更できる（Ch16はプロジェクト用で使えない）。

## 構成

```
run.py                 エントリポイント
sequencer/core.py      シーケンスエンジン（スケジューラ・MIDI出力・オートメーション）
sequencer/web.py       WebSocket制御 + 静的ファイル配信
web/                   ブラウザUI（素のJS、ビルド不要）
scripts/midi_monitor.py  送信MIDIのモニタ
```
